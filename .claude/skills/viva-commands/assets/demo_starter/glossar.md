# Glossar

Manifest: Die Datei `_main_.md` eines Dokuments; sie listet Titelseite, Kapitel und Verzeichnisse in ihrer Reihenfolge.
Befehl: Ein Aufruf in doppelten geschweiften Klammern, z. B. ein Bild oder eine Formel, den das Rendern prüft und der Konverter ins Word-Dokument schreibt.
Formatvorlage: Eine benannte Formatierung der Word-Vorlage, z. B. Base Text, Note oder Label.
Farbband: Der farbige Balken oben auf der Titelseite und auf jeder Kapitelseite, mit Titel und Logo.
Platzhalter: Ein Dateiname in doppelten runden Klammern für ein Bild, das noch fehlt.
Lernziel: Eine überprüfbare Aussage, was Lernende nach dem Kapitel können; nummeriert mit LZ und einer Zahl.
Inhaltssteuerelement: Ein Bereich im Word-Dokument, der einen Block mit seiner uuid kennzeichnet.
